# Inspect Neeto Record evidence

Use the connected Neeto Record MCP tools. Tool names can differ by client, so inspect the available recording, transcript, and screenshot capabilities first.

1. Extract the recording URL or ID from the issue and every comment.
2. Read accessible recording metadata and the transcript for context.
3. Request screenshots around the relevant actions and failure. Inspect the returned images, including the state before and after the failure.
4. Record the recording URL, timestamps, visible actions, inputs, and results.

Do not open Neeto Record recordings in a browser. A transcript or title alone does not establish what appeared on screen. Distinguish visible evidence from spoken claims and inference.

If the integration is missing or access fails, report the exact gap and continue with accessible evidence. Ask for missing context only when it blocks a material conclusion. Do not invent tool names, claim to have watched inaccessible material, or require the user to repeat checks the agent can perform.
